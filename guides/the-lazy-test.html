The Lazy Test: should you build an agent for it?

Not everything deserves an agent. Five questions tell you in a minute.

Any toolMindset4 min read

My motto

Professionally lazy: if I have to do it twice, a machine should do it next time. But building takes time too, so I check first.

The five questions

  1. Repeat. Will I do this at least once a week?
  2. Rules. Can I write down the steps in plain words?
  3. Stakes. If it goes wrong, is the damage small, or can I check the result before it goes out?
  4. Time. Does building it take less than ten times one manual run?
  5. Data. Is the input easy to get, like a feed, an inbox or a page?

4 or 5 yes: build it. 2 or 3: do it by hand once more and write down the steps. 0 or 1: keep doing it yourself.

Example

Reading tender notices every morning: weekly, clear rules, a human reads the digest, an afternoon to build, public feed. Five yes, so I built the agent.
