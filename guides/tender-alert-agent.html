Build a tender alert agent that costs 0 EUR

Public tenders hide in thousands of notices. This agent reads them every morning and sends you only the ones that fit.

PythonAgent8 min read

What you build

A small Python script that runs every morning on GitHub Actions (free), pulls new public tenders, filters them, adds the deadline and a working link, and emails you one tidy digest.

  1. Fetch. Pull the day's new notices from the public tender feed.
  2. Filter. Keep only the ones that match your keywords and sector codes.
  3. Enrich. Add the deadline and link from the original eForms record.
  4. Clean. Remove duplicates and notices that already closed.
  5. Send. One email, newest and closest deadline first.

The three bugs that cost me days

1. Missing links

Some notices come without a link. Use a fallback chain: direct link, then the buyer's profile page, then a search link built from the notice ID. Never send an item with no way to open it.

2. Wrong deadlines

The feed's deadline field is often empty or wrong. Read it from the original eForms record instead, and skip the item if you cannot find one.

3. Keywords alone are not enough

A search for "well renovation" also returned the renovation of a town fountain. Combine keywords with sector codes (CPV) so only real matches get through.

Run it for free

Put the script in a GitHub repository, add a scheduled workflow (cron) and store the email credentials as repository secrets. GitHub runs it every morning, no server needed.

on:
  schedule:
    - cron: "0 6 * * *"
jobs:
  digest:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install -r requirements.txt
      - run: python agent.py
        env:
          SMTP_PASS: ${{ secrets.SMTP_PASS }}
