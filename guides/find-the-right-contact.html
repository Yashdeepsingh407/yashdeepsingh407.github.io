Guide

Find the right contact at any company with Claude

Cold outreach fails when it goes to the wrong person. Let an AI do the reading and keep a source for every name.

ClaudeResearch6 min read

The idea

Give Claude a list of companies and a role (for example "head of partnerships"). It searches the web, reads the team and about pages, and returns the best-fitting person with the page it found them on.

Steps

  1. Define the role. Write who you want in one line, plus two alternatives if that title does not exist.
  2. Search and read. Ask Claude to open the company's team page and cite the URL for every person.
  3. Store it with IDs. Put results in a linked database so each person, company and source has an ID. No loose spreadsheets.
  4. Check. Skip anyone without a public source. A name without a link is a guess.
  5. Write the first line by hand. The AI finds the person; you decide what to say.

A prompt to start with

For each company below, find the person responsible for [ROLE].
Use only public pages. For every person return: name, title,
the exact URL where you found them, and how sure you are (high/medium/low).
If you cannot find a public source, write "not found". Do not guess.

Keep it legal

Only use publicly listed business contacts, keep the source for each one, and give people an easy way to say no. In the EU this is covered by GDPR, so check the rules for your case first. This is general information, not legal advice.
