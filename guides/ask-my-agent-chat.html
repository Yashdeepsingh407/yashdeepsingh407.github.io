Build the Ask my agent chat for your own site

The chat on my homepage looks like AI but runs on pre-written answers. That makes it fast, free and always on brand.

WebWeb build7 min read

Why pre-written

A real model costs money per message, can say wrong things about you, and needs a server. For a portfolio, ten good answers cover almost every question.

Steps

  1. Pick the questions visitors really ask: who are you, what did you build, can I hire you.
  2. Write the answers short, in your voice, with a link when it helps.
  3. Add chips (buttons) so people tap instead of type.
  4. Fake the thinking with a typing indicator of about 600 ms.
  5. Keep it accessible so the chat works with a keyboard and a screen reader.

The core in 12 lines

const answers = {
  who:  "I'm Yashdeep, I build AI agents in Berlin.",
  hire: "Yes. Message me on LinkedIn."
};
document.querySelectorAll('[data-q]').forEach(btn => {
  btn.onclick = () => {
    addMsg('me', btn.textContent);
    showTyping();
    setTimeout(() => addMsg('bot', answers[btn.dataset.q]), 600);
  };
});
